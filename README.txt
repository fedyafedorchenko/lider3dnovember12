ИНСТРУКЦИЯ ПО ПУБЛИКАЦИИ:
1. Распакуйте ZIP. Не загружайте ZIP одним файлом в репозиторий!
2. Откройте ваш репозиторий GitHub с отчётом.
3. На вкладке Code нажмите Add file > Upload files.
4. Перетащите ВСЕ ПЯТЬ файлов index.html, direct.html, smm.html, seo.html, tasks.html из папки архива. Файл index.html должен находиться в корне публикации.
5. При появлении вопроса о совпадающих именах замените старые файлы. Нажмите Commit changes.
6. Settings > Pages: main, /(root) (или выбранная вами директория публикации).
7. Откройте адрес сайта и при необходимости обновите его без кеша (Shift+Cmd+R на Mac).

Внимание: GitHub Pages — общедоступный хостинг. noindex не закрывает содержимое от других пользователей. Для внутреннего отчёта с коммерческой информацией нужен приватный способ доступа.
